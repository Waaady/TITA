# Work diary

One file per working session, named by date. What was attempted, what
happened, where it stopped, and the first thing to do next time.

Different from [`../status.md`](../status.md), which is the *current* state and
gets overwritten; the diary is append-only history. Different from
[`../experiments/`](../experiments/), which records measurements — the diary
records the work around them.

Write the entry at the end of the session, while the details are still there.
The most valuable line is always **"where exactly did we stop"**.

# `thesis/` — the written thesis

The LaTeX source of the thesis document.

Keeping it in the same repository as the code is a deliberate trade-off:

- **For**: figures, numbers and text stay in sync with the commit that produced
  them; one thing to back up; the git history shows code and writing progressing
  together.
- **Against**: the repository can no longer be published as code without also
  publishing the draft. If you intend to open-source the code, split this out
  before doing so.

If your university or supervisor requires a separate submission repository,
move this directory out early rather than late.

## Suggested layout

```
thesis/
├── main.tex
├── chapters/
├── bibliography/refs.bib
└── figures/          -> generated by notebooks/ into docs/images/
```

## Notes

- Build artifacts (`.aux`, `.log`, `.pdf` intermediates) are gitignored; see
  `.gitattributes` and `.gitignore` at the repo root.
- Cite the exact commit hash for every experiment you report, and the pinned
  upstream versions from `tita.repos`. It is the cheapest possible defence
  against "can you reproduce this?".
- Figures should be generated, not hand-edited. A hand-edited figure cannot be
  regenerated when the underlying number changes — and it will change.

# ---------------------------------------------------------------------------
# On-robot dependencies - Jetson Orin NX 16GB, JetPack 6.0 (L4T r36.3),
# CUDA 12.2, Ubuntu 22.04, Python 3.10, ROS 2 Humble.
#
# Install into the interpreter ROS uses, and pin numpy in the same command:
#
#   sudo apt install python3-pip
#   /usr/bin/python3 -m pip install -r requirements-jetson.txt
#
# DO NOT `pip install -r requirements.txt` on the Jetson - it would pull a
# CPU-only torch and desktop CUDA wheels that cannot load here.
#
# Never pip-install on the Jetson:
#   opencv-python   JetPack ships cv2; the PyPI wheel replaces it with a
#                   CPU-only build and breaks the camera pipeline
#   numpy>=2        ROS Humble's cv_bridge is built against the 1.x ABI
#   tensorrt, pycuda, cuda-python   come with JetPack
#   rclpy, cv_bridge, tf2_ros       come from apt (/opt/ros/humble)
#
# Verified 2026-09-18: the CPU path below runs detector_node on the robot
# (YOLOX-s 640: ~1.1 s/frame - not navigation-grade, but proves the plumbing).
# ---------------------------------------------------------------------------

# --- CPU inference (works today, deploy guide step 5) ----------------------
numpy>=1.24,<2.0
pyyaml>=6.0
onnxruntime>=1.17            # aarch64 CPU wheel is on PyPI

# --- GPU inference: NOT pip-installable for JetPack 6.0 ---------------------
#
# NVIDIA withdrew the prebuilt CUDA 12.2 wheels in 2025 ("limited resources").
# The Jetson AI Lab index (https://pypi.jetson-ai-lab.io/) now only serves
# jp6/cu126, cu128, cu129 - those need JetPack 6.1+ and will not load on 6.0.
# Do not add --extra-index-url for it here; the old .dev URL is 410 Gone.
#
# Working routes for JetPack 6.0, in order of preference:
#
#   1. TensorRT natively - DONE 2026-09-18, this is the deployed path.
#      TITA ships the TensorRT *runtime* libraries only. The Python binding,
#      trtexec, the CUDA compiler and two header packages had to be added:
#        sudo apt install python3-libnvinfer libnvinfer-bin cuda-nvcc-12-2 \
#                         cuda-profiler-api-12-2 libcurand-dev-12-2
#      Then pycuda, built from source against JetPack's CUDA (~5 min):
#        export PATH=/usr/local/cuda/bin:$PATH CUDA_ROOT=/usr/local/cuda
#        /usr/bin/python3 -m pip install pycuda
#      Then the engine, ON THE ROBOT (device- and version-locked):
#        bash scripts/build_engine.sh          # trtexec, fp16, ~10 min
#      Backend: tita_perception/detectors/yolox_tensorrt.py (TensorRT 8.6 API).
#      Measured: trtexec GPU compute 7.2 ms/frame vs ~1100 ms on the CPU.
#
#   2. onnxruntime-gpu wheel for JetPack 6.0 / cp310 from the Jetson Zoo
#      (https://elinux.org/Jetson_Zoo, ONNX Runtime section), if still
#      hosted. Uninstall the CPU onnxruntime first, install the .whl, then
#      set detector.device: cuda. Zero code changes.
#
#   3. PyTorch 2.4 for JetPack 6.0 - verified available at
#      https://developer.nvidia.com/w/compute/redist/jp/v60/pytorch/
#      (~1.5 GB). torchvision must then be built from source to match, and
#      the yolox package installed with --no-deps (it lists opencv-python).
#      Works, but puts a training framework on the robot.
#
#   4. jetson-containers (NVIDIA's own recommendation) - Docker image with
#      onnxruntime-gpu prebuilt for r36.3. Robust, but ROS inside a
#      container is extra integration work; see docker/README.md.
#
#   Do NOT upgrade JetPack to 6.1/6.2 to get the pip index back: the DDT SDK
#   is built for 6.0 and may break.

## First launch of `detector_node`

Against `indoor_run_02_moving` replayed with `--clock --loop`,
`use_sim_time:=true`. The node got through launch, parameter loading, config
and `build_pipeline` — **all ROS plumbing works** — and died at
`import onnxruntime`.

Cause: `pip3` had installed into a different Python than `/usr/bin/python3`,
which is what the node runs under. Installed with
`/usr/bin/python3 -m pip install onnxruntime` — which then pulled
**numpy 2.2.6** as a dependency. That breaks `cv_bridge` (built against the
1.x ABI). Fix issued: `/usr/bin/python3 -m pip install "numpy<2"`.
